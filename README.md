# CUSTOMPEN

A redesign concept for [penumbrafoundation.org](https://www.penumbrafoundation.org), the NYC photography non-profit at 36 East 30th Street.

All copy, prices, membership tiers and images come from the live Squarespace site, crawled on 2 Nov 2026. None of it is invented. What's new is the structure, the interface and the design system. Bookings, payments and sign-ups are handed off to the official site: this preview never takes money.

## What changed vs. the live site

| Live site (Squarespace) | CUSTOMPEN |
|---|---|
| 7-slide autoplay carousel homepage | Static editorial hero + a numbered **contact sheet** of the season's stories |
| 6 folders / 35 nav links, dated event pages in the global nav | 5 groups (Learn · Exhibitions · Programs · Tintype · Visit) + Shop, mega-menu with a feature image |
| Workshop filters at the bottom; "Flash Sale" / "Thanksgiving Promo" ghost categories | Filters at the top, every filter a URL key, live counts, "hide fully booked", search |
| Tuition dropdown reads "Select Select / TuitionMember Tuition…" | Every tuition tier shown with price and availability before you choose |
| Sold-out classes: dead button | Waitlist email pre-filled with the class and tier |
| 64-item shop, ~60% sold out, "Domestic shipping" sold as a product, 17 categories | Sold-out hidden by default (archive toggle), shipping moved to the cart, 4 shelves, payment-plan variants grouped |
| Membership prices only on 7 separate pages | All 7 tiers side by side + a full comparison table |
| No search | Site-wide search (⌘/Ctrl K) over 383 pages, workshops, classes and products |
| Empty / filename image alt text | Alt text on every image (captions and titles, with fallbacks) |
| "Sign In / My Account" links to `#` | Removed until real accounts exist |
| Dead links to past workshops (404) | Rerouted to the current index |

## Stack

- React 19 + React Router 7 + Vite 6, static SPA, deployed on Vercel
- Content: `public/data/*.json`, generated by `scripts/extract.py` from the Squarespace `?format=json` API (273 pages, 110 products)
- Images served from Squarespace's CDN with `?format=` srcsets and the site's stored focal points
- Fonts: Newsreader (reading and titles), Instrument Sans (UI), JetBrains Mono (dates and prices)
- No runtime dependencies beyond React

## Refresh content

```bash
pip install beautifulsoup4 lxml
bash scripts/crawl.sh     # re-crawls the live site and rewrites public/data
npm run build
```
